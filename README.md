# LAB7 Pathfinding

Proyecto de Unity 6000.3.14f1 con el ejercicio resuelto 2D y los ejercicios propuestos.

Abrir esta carpeta en Unity Hub. La escena Assets/Scenes/Pathfinding.unity contiene el ejercicio resuelto. Assets/Scenes/PathfindingPropuesto.unity añade paredes y un segundo enemigo. Las flechas mueven y orientan al jugador.

Assets/Tutorial3D/Scenes/AStarPath.unity contiene el laberinto 3D de The A* Algorithm. Durante Play, P selecciona el inicio y la meta, C avanza un paso de la búsqueda y M muestra la ruta final.

Los scripts del tutorial se basan en las soluciones guiadas S0406 y S0407 de Unity Learn y tienen sus comentarios en español. El informe y las capturas se entregan por separado.

Recursos del tutorial: https://learn.unity.com/course/artificial-intelligence-for-beginners/unit/a-36369ng?version=6.0

Navegación 2D: A* Pathfinding Project Free 4.2.17 de Aron Granberg. https://arongranberg.com/astar/download
